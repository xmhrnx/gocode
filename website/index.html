A coding agent that doesn't eat your RAM.

GoCode is a coding agent written in Go and drawn straight to the GPU. There is no browser engine inside it, so it opens instantly, stays fast through a thousand-message chat and leaves your memory for the code you're actually running.

Everything an agent needs. Nothing it doesn't.

A real agent loop

Streams, calls tools, reads results and keeps going until the job is done. Send messages while it works; they reach it at the next step.

Runs your commands

Builds, tests and git in your own shell, with a timeout and a clean stop. Git Bash or PowerShell on Windows, your $SHELL elsewhere.

Any model you like

Anthropic, OpenAI, Gemini, OpenRouter, DeepSeek and over 200 more, plus LM Studio, Ollama, llama.cpp and any OpenAI-compatible endpoint.

You stay in control

Approve each tool call with the diff in front of you, or pick a mode: ask, auto-accept edits, full access, read-only or chat only.

Sub-agents, MCP, skills

Hand big searches to sub-agents with their own context. Plug in MCP servers and Agent Skills. Long chats compact themselves.

Made to be lived in

Nine themes, searchable settings, editable prompts, image paste, text selection across messages and tabs that reopen where you left them.
